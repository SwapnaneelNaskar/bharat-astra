### 4. 🧮 18% GST Calculation Engine & Invoice Generator
- Dedicated **GST Calculation Console** modal providing step-by-step mathematical proof:
  1. `Raw Cart Subtotal = ∑ (Item Price × Quantity)`
  2. `Coupon Savings = Subtotal × Discount %`
  3. `Taxable Base Amount = Subtotal - Discount`
  4. `Central GST (CGST @ 9%) = Taxable Base × 0.09`
  5. `State GST (SGST @ 9%) = Taxable Base × 0.09`
  6. `Total GST (18%) = CGST + SGST`
  7. `Delivery Fee = ₹0 (FREE over ₹999)`
  8. `Grand Total = Taxable Base + Total GST + Delivery`
